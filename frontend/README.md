# Planora Frontend

React + Vite + Bootstrap interface for SubscriptionPlan Management.

## Run in VS Code
1. Extract the frontend ZIP.
2. Open the extracted folder in VS Code.
3. Install Node.js 20+ (Node 22 recommended).
4. Open Terminal and run `npm install`.
5. Run `npm run dev`.
6. Open the URL printed by Vite (usually http://localhost:5173).

Backend must run at `http://localhost:8080`. To change it, copy `.env.example` to `.env` and set `VITE_API_URL`. Restart Vite after changing `.env`.
